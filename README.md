## 🚀 Quick Start

### Compile and Run (Example)

```bash
# Navigate to a specific exercise
cd C00/ex00

# Compile the C file
gcc -Wall -Wextra -Werror ft_putchar.c -o program

# Run the program
./program
```

### Shell Scripts

```bash
# Navigate to shell exercise
cd Shell01/ex01

# Give execute permission
chmod +x print_groups.sh

# Run the script
./print_groups.sh
```
